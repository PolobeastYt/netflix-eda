# Netflix EDA — Exploratory Data Analysis

## Overview
An exploratory data analysis of Netflix's movie and TV show catalog using Python, Pandas, Matplotlib and Seaborn.

## Key Findings
- Netflix's catalog is made up of roughly 70% movies and 30% TV Shows
- The United States, India and the UK produce the most Netflix content
- Content production exploded after 2015, peaking around 2019-2020
- TV-MA is the most common content rating
- The director and cast columns have the most missing data

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## How to Run
1. Clone the repository
2. Install dependencies: `pip install pandas matplotlib seaborn`
3. Open `netflix_eda.ipynb` in Jupyter or VS Code
4. Run all cells

## Dataset
[Netflix Movies and TV Shows](https://www.kaggle.com/datasets/shivamb/netflix-shows) from Kaggle
